Detailed Description

SDL3_mixer derriere IAudioModule.

SDL3 a remplace le peripherique global de SDL2 par un MIX_Mixer explicite qu'on possede. C'est lui qui fabrique les tampons et les pistes, donc le module le tient et le passe a chaque objet qu'il cree.

Ce module est independant du module graphique : on peut prendre le son de SDL3 et l'image de sfml.
